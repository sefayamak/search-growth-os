# Reports

- `runs/` — git-ignored scratch: `*.crawl.json`, `*.audit.json`, `*.audit.md` from `npm run cli -- audit`.
- `dry-run-template.md` — the shape every dry-run audit follows (generated by `src/report.ts`).
- `changelog.md` — IMPLEMENTED_CHANGE log per site (date, PR, pages, experiment id) so later analysis separates site changes from search movement.
- `learning.md` — what worked and what did not for each site (VERIFIED_RESULT only).
- `alerts.log` — appended by scheduled audits (critical/high only); tailed by the monitor. Absent until a scheduled job exists.
- `phase1-acceptance.md` — evidence for the Phase 1 acceptance gate.
